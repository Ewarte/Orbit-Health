# src/lib

**Qué va aquí:** Utilidades sin pantalla que usa más de una pieza.

**Quién:** Quien la necesite; avisar al grupo

**Ahora hay:**
- `i18n.ts`, `useI18n.ts`, `I18nProvider.tsx`: idiomas (español por defecto, inglés). Todo texto visible va en `i18n.ts`.
- `domainText.ts`: traduce nombres, unidades, valores, razones y fechas de los indicadores.
- `missionTime.ts`: tiempo de misión (UTC, MET, día de vuelo, Marte) y reloj para la rutina.
- `status.ts`: estilo de cada estado y cálculo del peor estado.
